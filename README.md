# Campora

Campora is an interactive campus quiz web application designed to make campus-related learning and knowledge testing more engaging.

## Features

- User login with name
- Interactive quiz interface
- Campus-related multiple-choice questions
- Questions loaded dynamically from a JSON file
- Attempted and unattempted question tracking
- Review questions before submission
- Selected-answer highlighting
- Instant correct/incorrect feedback
- Progress tracking
- Countdown timer
- Manual quiz submission
- Final score display
- Reattempt option
- Responsive user interface

## Tech Stack

- HTML
- CSS
- JavaScript
- JSON
- DOM Manipulation

## How It Works

1. Enter your name to start the quiz.
2. Answer the questions displayed on the screen.
3. Navigate through questions using the progress controls.
4. Review questions that need another look.
5. Submit the quiz manually or let the timer end the quiz automatically.
6. View your final score.
7. Reattempt the quiz if needed.
